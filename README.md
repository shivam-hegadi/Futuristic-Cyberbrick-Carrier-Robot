# Futuristic-Cyberbrick-Carrier-Robot

A small 3D printed robot designed to carry items using Bambu Lab CyberBrick parts.

The robot has two motorized wheels and a sphere front wheel for turning. The carrying platform is mounted on 4 springs to help keep items stable while the robot is moving.

The body and most of the custom parts were designed in Fusion 360 and 3D printed in Clear PLA to look more futuristic. The design includes a battery compartment, removable top cover, gearbox mounts, receiver mounts, and an LED board.

The robot is controlled with a CyberBrick controller using tank drive. The LEDs are also used as status lights based on the robot's movement.
